# ✅ To Do List App 📝

Una aplicación web interactiva para gestionar tareas de forma rápida y sencilla.

---

## 🚀 Requisitos Funcionales

* 🏷️ DEBE mostrar las categorías o estados de las tareas.
* 📂 DEBE permitir abrir y cerrar el panel lateral de tareas.
* ➕ DEBE añadir una nueva tarea a la lista.
* 🗑️ DEBE permitir eliminar tareas.
* 🧮 DEBE actualizar los contadores y estadísticas en tiempo real.

---

## 💻 Tecnologías Utilizadas

* 🌐 HTML5
* 🎨 CSS3
* ⚡ JavaScript
